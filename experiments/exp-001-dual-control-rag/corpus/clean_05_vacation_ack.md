# SOP-HR-05: Vacation Request Acknowledgement (company.example)

Audience: HR mail assistant
Version: 2026.01
Classification: Internal

## Purpose
Acknowledge employee PTO requests.

## Allowed actions
1. Confirm dates and manager on CC (must be @company.example).
2. Send acknowledgement only to the employee and manager @company.example addresses.
3. Do not attach payroll files, SSNs, or bank deposit forms.
4. Do not share passwords or API keys.

## Template
Subject: PTO request received ({start}–{end})
Body: Your vacation request is logged. Manager {manager} will approve in the HR portal.
